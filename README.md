# ECEN 403/404 Matrix 2 Electric Scooter

Shared repository for the Matrix 2 ECEN 403/404 senior design project.

## Repository Contents

- `firmware/` - Embedded controller and ESP32 firmware
- `mobile-app/` - Mobile application source code
- `hardware/` - PCB layouts, schematics, BOMs, and manufacturing files
- `interfaces/` - Communication protocols, pinouts, and subsystem interfaces
- `testing/` - Test procedures, results, and validation files
- `docs/` - Reports, presentations, requirements, and project documentation
- `references/` - Datasheets, papers, and reference designs

## Team Workflow

Do not make major changes directly on `main`.

Create a branch for your work, commit your changes, and open a pull request before merging into `main`.
