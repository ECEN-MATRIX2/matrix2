# Capstone ZIP import

This contribution contains only material supplied in `Github Zip.zip`, plus organization and documentation of that material. Existing team matrix designs are outside its scope.

- [FPGA projects](../../firmware/fpga/README.md): ECEN 403 Vivado project and four separate ECEN 404 variants.
- [KiCad project settings](../../hardware/capstone/project-settings/README.md): the two supplied `.kicad_pro` files.
- [Import manifest](import-manifest.json): all archive files, retained destinations, SHA-256 hashes and exclusions.

108 supplied files are retained. 365 generated or byte-identical duplicate files remain available in the original ZIP. Imported source bytes are unchanged.

The ZIP contains no `.kicad_sch` or `.kicad_pcb` files. No schematic/layout exports, component inventory or IC datasheets are attributed to this contribution. Those require the actual source design files from this contributor. No FPGA build or simulation was performed during organization.
